### **ChurnMap – Customer Churn Insights**

* **Analyzed** 1,500 subscription customers using **Excel, SQL, Python, and Power BI**, identifying an overall **18.9% churn rate** and key customer retention patterns.
* **Cleaned and transformed** customer data using Excel and Python, applying data-quality checks and creating analysis-ready datasets for cross-tool validation.
* **Investigated** churn drivers using SQL and Python across contract type, tenure, usage, login frequency, and unresolved complaints, identifying **51.5% churn in the compound high-risk segment**.
* **Built and evaluated** Logistic Regression and Random Forest models to predict churn probability and score **1,216 active customers** for targeted retention analysis.
* **Developed** a 3-page Power BI dashboard covering **Churn Trends, Cohort Analysis, and At-Risk Customers**, enabling interactive monitoring of churn and retention insights.
